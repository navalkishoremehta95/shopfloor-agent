# ShopFloor Agent

Procedure-compliant assembly assistant — notebooks.

Grounded in MIAM / M3-HRC industrial assembly (FRAS kit).

## Notebooks

- [notebooks/01_sop_graph.ipynb](notebooks/01_sop_graph.ipynb) — Part 1 SOP graph
- [docs/sop_samples/miam_assembly_subset.md](docs/sop_samples/miam_assembly_subset.md) — MIAM assembly subset
- [docs/sop_samples/assembly_sop_v1.md](docs/sop_samples/assembly_sop_v1.md) — toy SOP

## Setup

```bash
pip install -r requirements.txt
jupyter notebook notebooks/01_sop_graph.ipynb
```
