# Assembly101 toy subset (validation SOP)

Simplified procedure for one Assembly101-style toy vehicle.
Used to validate ACT / WAIT / GUIDE on public mistake annotations
([Assembly101 mistake detection](https://github.com/assembly-101/assembly101-mistake-detection), CC BY-NC 4.0).

Not a substitute for MIAM / M³-HRC; cross-domain check of the same pipeline.
